AV · Air vehicle

Flight controller, GNSS receiver, inertial and air-data sensors, maintenance ports.

IDSTRIDEThreatControlsResidual risk
AV-S1SpoofingCounterfeit GNSS signals produce a false position and time that the flight controller accepts as truth.C-NAVXC-GNSSAUTHSlow carry-off is detected only once it exceeds what independent sensors can explain.
AV-T1TamperingParameters or firmware altered through a maintenance port during storage or maintenance.C-BOOTC-DEBUGC-PHYSC-LOGInsider with legitimate maintenance access.
AV-R1RepudiationA configuration or flight-mode change cannot be attributed to a person or a message.C-LOGC-SIGNClock drift without authenticated time weakens ordering across nodes.
AV-I1Information disclosureA lost or captured airframe exposes link keys, mission data and stored imagery.C-KEYC-DATAData in volatile memory at the moment of capture.
AV-D1Denial of serviceGNSS jamming or sensor saturation removes navigation inputs.C-NAVXC-DIVVision-based fallbacks fail over featureless terrain, at night without infrared, or in smoke.
AV-E1Elevation of privilegeAn unsigned image or open debug interface gives full control of the flight controller.C-BOOTC-DEBUGHardware-level fault injection by a well-resourced attacker with physical access.

CC · Companion computer

Onboard processor running autonomy, perception and payload software beside the flight controller.

IDSTRIDEThreatControlsResidual risk
CC-S1SpoofingA process on the onboard network impersonates the autopilot or a sensor to other onboard software.C-SEGC-SIGNShared-memory or bus designs without per-component identity.
CC-T1TamperingAutonomy, perception software or model files are modified.C-BOOTC-SBOMC-REPROModels are hard to review; integrity proves origin, not correctness.
CC-R1RepudiationAn autonomous decision cannot be reconstructed afterwards.C-LOGC-CMLog volume limits on small platforms force summarisation.
CC-I1Information disclosurePayload imagery or intelligence leaks through network services running on the companion computer.C-DATAC-LEASTC-TLSDebug and development services left enabled in the field.
CC-D1Denial of serviceResource exhaustion or a crash stops perception and autonomy mid-mission.C-RTAC-SEGMission capability is lost even when flight safety is preserved.
CC-E1Elevation of privilegeA compromised companion computer reaches flight control through an unrestricted bus.C-SEGC-LEASTC-CMDAUTHZAllow-listed commands can still be misused within their bounds.

DL · Command and telemetry datalink

Radio links carrying commands up and telemetry and video down.

IDSTRIDEThreatControlsResidual risk
DL-S1SpoofingCommands from an unauthenticated source are accepted because the link does not authenticate messages.C-SIGNC-KEYKey compromise on any endpoint that holds the key.
DL-S2SpoofingA recorded, validly authenticated command is replayed later.C-SIGNFreshness depends on correct timestamp handling and clock sanity at both ends.
DL-T1TamperingTelemetry is altered in transit so the operator acts on a false picture.C-SIGNC-ENCUnauthenticated video downlinks.
DL-R1RepudiationA command cannot be tied to one ground station because a single key is shared across the fleet.C-KEYC-LOGShared keys remain common for operational convenience.
DL-I1Information disclosureTelemetry and video reveal position, mission and operator location to a passive listener.C-ENCEmissions remain detectable and locatable even when encrypted.
DL-D1Denial of serviceRadio jamming or message flooding denies command and control.C-DIVC-RATEPhysics: a sufficiently powerful jammer in the right geometry wins.
DL-E1Elevation of privilegeConfiguration, firmware upload or arming commands are accepted from any authenticated sender in any flight phase.C-CMDAUTHZC-SIGNAuthorisation policy errors.

GCS · Ground control station

Operator laptop or tablet running mission planning and control software.

IDSTRIDEThreatControlsResidual risk
GCS-S1SpoofingStolen operator credentials let someone operate as the pilot.C-MFAC-EPSession hijacking on an already compromised host.
GCS-T1TamperingA mission plan, geofence or map file is altered before upload.C-INTEGC-EPPlans edited in the field under time pressure.
GCS-R1RepudiationAn operator action cannot be attributed because accounts are shared.C-MFAC-LOGPhysical access to an unlocked station.
GCS-I1Information disclosureA lost laptop exposes keys, plans, imagery and credentials.C-DATAC-KEYData copied to removable media.
GCS-D1Denial of serviceMalware or an untested update disables the station during a mission.C-EPC-SPAREC-IRCommon-mode failure if spares share the same image.
GCS-E1Elevation of privilegeUnpatched software allows local privilege escalation to the control application and its keys.C-EPC-LEASTVulnerabilities not yet known or patched.

API · Cloud and fleet API

Backend for fleet management, flight logs, media, tasking and updates.

IDSTRIDEThreatControlsResidual risk
API-S1SpoofingA leaked bearer token grants API access with no further authentication.C-TOKENC-MFATokens stolen from a compromised endpoint within their lifetime.
API-T1TamperingUploaded flight logs, missions or fleet configuration are altered in the backend.C-INTEGC-LOGC-APIPrivileged backend administrators.
API-R1RepudiationAPI actions such as tasking or configuration changes leave no attributable audit trail.C-LOGLogs held by the same provider that is being audited.
API-I1Information disclosureBroken object-level authorisation exposes another tenant's telemetry and flight history.C-APIC-LEASTNew endpoints added without the same checks.
API-D1Denial of serviceAPI abuse or outage blocks synchronisation, tasking and updates.C-RATEC-OFFLINEFeatures that genuinely depend on the cloud.
API-E1Elevation of privilegeBroken function-level authorisation lets an ordinary user reach administrative functions such as pushing updates.C-APIC-LEASTC-STAGEDMisconfigured roles.

SC · Supply chain and update path

Hardware components, third-party software, build pipeline, signing keys and update distribution.

IDSTRIDEThreatControlsResidual risk
SC-S1SpoofingA counterfeit component or an impostor update server is accepted as genuine.C-SBOMC-BOOTC-TLSCounterfeits that are functionally identical until they fail.
SC-T1TamperingA malicious or vulnerable third-party component enters the build.C-SBOMC-REPROVulnerabilities in components that are correctly inventoried but not yet disclosed.
SC-R1RepudiationNobody can establish which firmware and components were shipped on which unit.C-CMC-SBOMField modifications outside configuration control.
SC-I1Information disclosureSource code or signing keys leak from the build pipeline.C-KEYC-LEASTInsiders with legitimate access.
SC-D1Denial of serviceA faulty update disables the fleet, or a sole-source part becomes unavailable.C-STAGEDC-CMLong-lead obsolescence.
SC-E1Elevation of privilegeA compromised build system signs attacker-supplied code with genuine keys.C-KEYC-REPROSigning infrastructure is a single point of trust.
